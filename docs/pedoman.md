# Pedoman Studio

Pedoman Pelaksanaan Studio Perancangan Arsitektur merupakan acuan bagi dosen dan mahasiswa dalam melaksanakan pembelajaran studio secara terarah dan konsisten. Pedoman memuat sistem pembelajaran studio, tahapan proses perancangan, mekanisme asistensi, ketentuan output, sistem evaluasi dan penilaian, tata tertib, penggunaan ruang studio, serta dokumentasi pembelajaran.

Pedoman ini menjadi standar umum pelaksanaan studio, sedangkan ketentuan khusus mengenai objek perancangan, tema, target capaian, jadwal, dan output pada masing-masing Studio Perancangan Arsitektur mengacu pada RPS dan TOR yang berlaku.
